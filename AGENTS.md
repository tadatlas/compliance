# Rules for agents in this repo

These apply to every task in `compliance`, on top of the specific brief you are following.

1. **Read-only on source systems.** Never create, edit or delete anything in Notion (including the COMPLIANCE databases), AgentBox, DatoCMS, the website or any portal. Only write files inside this repo.
2. **Official sources only for the law.** Read NSW Fair Trading, NSW Legislation, the Federal Register of Legislation or AUSTRAC with Playwright. Industry and media sites are hints, never the source.
3. **Flag, don't rule.** You surface issues for a licensee to decide. Never state that a breach, underquoting or misconduct *has occurred*. Use the severity scale in the brief.
4. **Quote, don't paraphrase.** Every finding cites the exact text or field value it relies on.
5. **No guessing.** If the data can't prove it, it's *Needs evidence*.
6. **Calibrate first.** Run the brief's calibration step before any live audit and stop for review.
7. **Never overwrite reports.** Each run writes new dated files.
8. **Australian English**, plain and concise.
9. **No personal data beyond what the listing already publishes.** Don't pull vendor, buyer or tenant details into reports.
